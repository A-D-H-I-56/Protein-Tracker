Developer REST API

Programmatic integration for fitness apps, client portals, and nutrition systems with JSON endpoints.

API Endpoints Specification (v1)

Base URL: /api/v1
GET /api/v1/health

Health check verifying service uptime and ML model artifact readiness. 

curl -X GET http://localhost:5000/api/v1/health
POST /api/v1/predict

Generates complete personalized nutrition recommendation, BMR/TDEE baselines, and structured 4-meal plan.

Request Payload (JSON): 
{
  "age": 25,
  "gender": "Male",
  "weight": 70.0,
  "height": 175.0,
  "activity_level": "Very Active",
  "goal": "Muscle Gain"
}
Example cURL: 
curl -X POST http://localhost:5000/api/v1/predict \
  -H "Content-Type: application/json" \
  -d '{"age": 25, "gender": "Male", "weight": 70, "height": 175, "activity_level": "Very Active", "goal": "Muscle Gain"}'
GET /api/v1/metrics

Retrieves quantitative validation metrics (MAE, MSE, RMSE, R²) for all regression targets. 

curl -X GET http://localhost:5000/api/v1/metrics
POST /api/v1/explain?k=3

Returns top-K closest matching verified profiles with Euclidean distance similarity scores.
